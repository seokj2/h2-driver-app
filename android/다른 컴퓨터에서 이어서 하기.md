# 다른 컴퓨터(노트북)에서 기사 앱 이어서 하기

기사 앱(`android/`)을 다른 Windows 컴퓨터에서 빌드하고 플레오스 Connect 에뮬레이터로 돌리는 방법입니다.
비밀번호·API 키는 필요 없습니다(지도도 키 없는 오픈 지도).

## 1. 개발 환경 한 번에 깔기 (처음 한 번, 약 30~60분)

관리자 PowerShell에서:

```powershell
powershell -ExecutionPolicy Bypass -File android\tools\setup-pleos.ps1            # C:\PleosDev 에 설치
powershell -ExecutionPolicy Bypass -File android\tools\setup-pleos.ps1 -Root D:\PleosDev
```

- 받는 것: Android Studio(약 1.5GB), 명령줄 도구, JDK 21, Node LTS, 플레오스 Connect 에뮬레이터 이미지(약 4GB, 풀면 약 19GB). 디스크 약 25GB 필요.
- 플레오스 이미지는 SDK 저장소 XML `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml` 에 적힌 주소에서 받고 SHA1로 확인합니다.
- 실행하면 Google SDK 라이선스와 42dot(플레오스) SDK 라이선스에 동의하는 것으로 처리됩니다.
- 가상화: 에뮬레이터 하이퍼바이저 드라이버(AEHD)를 재부팅 없이 넣습니다. Hyper-V·WSL2가 켜진 노트북은 WHPX가 대신 쓰일 수 있습니다.
- 끝나면 `C:\PleosDev` 안에 전부 들어갑니다: `sdk`, `jdk-21`, `android-studio`, `avd\PleosConnect.avd`, `env.bat`, `start-emulator.bat`, `start-studio.bat`.

에뮬레이터 설정: AVD 이름 `PleosConnect`, 이미지 `system-images;android-34;pleos_car_emulator;x86_64`(Pleos Connect v2.1.0), 2560×1440 160dpi, RAM 4GB, GPU host, 매번 콜드 부트.

### 이미 Android Studio·플레오스 이미지가 깔린 컴퓨터라면(노트북에서 실제로 한 방법, 11/14)

설치 스크립트 없이 있는 SDK를 그대로 씁니다. 추가 공간은 2~3GB면 됩니다.

```powershell
mkdir C:\PleosDev
cmd /c mklink /J C:\PleosDev\sdk "%LOCALAPPDATA%\Android\Sdk"     # 있는 SDK를 바로가기로 연결
# JDK 21: https://aka.ms/download-jdk/microsoft-jdk-21-windows-x64.zip 을 받아 풀고 C:\PleosDev\jdk-21 로 연결(또는 그 자리에 풀기)
```

- **Java 25는 안 됩니다.** Android Studio 최신판에 든 Java(jbr)가 25면 이 프로젝트의 Gradle 8.14가 못 돌아서 JDK 21을 따로 씁니다.
- **경로에 한글이 있으면 빌드가 실패합니다.** 사용자 이름이 한글이면(`C:\Users\(한글 이름)\...`) 저장소를 `C:\PleosDev\h2-driver-app`처럼 영문 경로에 받습니다.
- 가상기기: 명령줄 도구(avdmanager)가 없으면 `C:\PleosDev\avd\PleosConnect.avd`와 `config.ini`를 직접 만들어도 됩니다(이미지 `system-images;android-34;pleos_car_emulator;x86_64`). RAM 8GB 노트북은 가상기기 RAM 3GB, Gradle 메모리 1.5GB로 줄이고 빌드를 먼저 끝낸 뒤 에뮬레이터를 켭니다.
- 가속 드라이버(AEHD)가 없으면 https://github.com/google/android-emulator-hypervisor-driver/releases 에서 받아 관리자 PowerShell에서 `silent_install.bat`(재부팅 필요 없음). `emulator -accel-check`로 확인.
- `C:\PleosDev\start-emulator.bat`: `"C:\PleosDev\sdk\emulator\emulator.exe" -avd PleosConnect -no-snapshot-load -gpu host` (ANDROID_AVD_HOME=C:\PleosDev\avd).

## 2. 코드 받기

```powershell
cd C:\PleosDev      # 영문 경로에 받기(한글 경로면 빌드 실패)
git clone https://github.com/seokj2/h2-driver-app.git
cd h2-driver-app
```

git이 없으면 GitHub에서 브랜치 zip을 받아도 됩니다(아래 `-Zip`).

## 3. 빌드·설치·실행·캡처 (매번, 약 1분)

```powershell
powershell -ExecutionPolicy Bypass -File android\tools\h2-build.ps1                  # git으로 받은 경우
powershell -ExecutionPolicy Bypass -File android\tools\h2-build.ps1 -Zip 브랜치.zip   # zip으로 받은 경우
```

- 에뮬레이터가 꺼져 있으면 켜고, APK를 설치해 앱을 띄운 뒤 `내려받기\h2_shot1.png`로 캡처하고 오류 로그를 보여 줍니다.
- `-PleosRoot D:\PleosDev`처럼 설치 위치를 바꿀 수 있습니다.
- 다른 컴퓨터에서 만든 APK가 깔려 있으면 서명이 달라 한 번 지우고 다시 깝니다(앱 안 시연 상태만 처음으로 돌아감).
- Android Studio로 하려면 `C:\PleosDev\start-studio.bat`로 열고 `android` 폴더를 엽니다.

## 4. Claude와 같이 할 때

1. 노트북에서도 Claude 데스크톱 앱을 켜고 이 프로젝트에 연결합니다.
2. 앱 안 브라우저 창에서 GitHub에 한 번 로그인합니다(비공개일 때만).
3. 그다음엔 지금처럼 "새로 푸시했어, 다시 돌려봐"라고 하면 Claude가 노트북에서 받아 빌드·설치·캡처까지 합니다.

코드 수정·테스트는 클라우드에서 하고(에뮬레이터 없이 `./gradlew :core:test :app:testDebugUnitTest`로 화면 PNG까지 확인), 에뮬레이터 확인만 컴퓨터에서 합니다.
앱 구조와 명령은 [README.md](README.md)를 봅니다.
